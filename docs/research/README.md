# Clio Research

Use this directory for evidence-backed research that informs a concrete Clio decision. Research notes should identify:

- the question and current requirement;
- sources and licenses where relevant;
- compatibility and maintenance implications;
- the decision or unresolved tradeoff;
- the affected boundary and verification plan.

Reference projects such as Paperback, Readest, FolioReader, Foliate, Calibre, TuxBooks, Foliate.js, and PDF.js are inputs, not templates. Do not copy GPL/AGPL application code into Clio. Readium remains research/reference only unless a concrete requirement justifies a dependency.
